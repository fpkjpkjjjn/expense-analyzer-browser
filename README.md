# Expense Analyzer

Для локального запуска в браузере из корня проекта выполните:

```powershell
cd expense-analyzer-api
python -m pip install -r requirements.txt
python api.py
```

Откройте [http://localhost:5000](http://localhost:5000). При следующем запуске
достаточно выполнить `python api.py` из папки `expense-analyzer-api`.
